# تدقيق الصفحات العامة — الدفعة 1

**النطاق:** 49 صفحة عامة فقط (بدون `/admin`).  
**التاريخ:** 27 سبتمبر 2026.  
**الحالة:** تدقيق وتصنيف فقط — **لا تعديل على الكود** حتى الموافقة.

**مصدر البيانات الحي في النظام:** `SPORTS_API_KEY` الحقيقي → `ApiFootballProvider` + كاش. بدون مفتاح → `DevelopmentProvider` يعيد قوائم فارغة أو «غير موجود» — **لا يخترع مباريات**.  
**البث:** `STREAMING_ENABLED = false` في `src/lib/streaming/flag.ts` — لا مشغّل ولا زر مشاهدة مرخّص.

**مفتاح التصنيف**

| الرمز | المعنى | إجراء بعد الموافقة |
|---|---|---|
| 🟢 GOOD | تصميم متسق مع لغة الموقع الحالية (Salon / Entity / hall / lex) + بيانات من Prisma أو API-Football أو RSS/YouTube الحقيقي | لا تُلمس |
| 🟡 PARTIAL | التصميم مقبول، لكن فيه نص/رقم ثابت يبدو كبيان تشغيلي أو نسخة مخترعة فوق سجل حقيقي | إصلاح البيانات/النسخ فقط |
| 🔴 BROKEN | الواجهة قديمة أو بلون مسرح (cyan/emerald) خارج نظام YS البرتقالي/الداكن | إعادة بناء الواجهة دون تغيير منطق الـ API |

**أبواب إعادة توجيه (تُحسب ضمن الـ 49 لأنها ملفات `page.tsx`):** `/` → `/ar`؛ `/video` → `/videos`؛ `/subscribe` → الرئيسية؛ `/tv-guide` و`/watch*` و`/vod*` → `/live` طالما البث مقفل.
